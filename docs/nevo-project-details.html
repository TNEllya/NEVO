核心特性

为什么选择 NEVO

专为实时语音通讯设计的技术栈，带来卓越的音频质量和安全保证

🎙️

低延迟音频

miniaudio 采集/播放 + Opus 编解码器，支持 20ms 帧长和带内 FEC 前向纠错。 自适应 JitterBuffer 去抖，网络抖动 ≤50ms 无感知。

🔐

端到端加密

XChaCha20-Poly1305 AEAD 加密，每个语音包独立 nonce。 自动密钥轮换机制，防止流量分析和重放攻击。

🌐

NAT 穿透

STUN 协议 UDP 打洞，智能探测 NAT 类型。 对称型 NAT 自动回退 TCP 隧道模式，确保在复杂网络环境下也能建立连接。

📡

层级频道系统

支持任意深度的频道树结构，每个频道独立的权限配置。 基于 SQLite3 的持久化存储，会话数据完整保留。

🖥️

跨平台桌面端

Qt 6 Widgets 原生 UI，可停靠面板设计。Windows / Linux / macOS 全平台支持， 统一用户体验。

📱

移动端原生支持

Android (Kotlin) 和 iOS (Swift) 原生实现，通过 JNI/C Interop 桥接 C++ 核心。 支持后台语音和蓝牙耳机。

📊

服务端仪表盘

实时会话监控、用户管理、频道管理。支持 Docker 一键部署， 健康检查自动探活，开箱即用。

🔄

优雅降级

所有可选依赖（Opus、libsodium、SQLite3、OpenSSL）缺失时自动降级为 stub 实现。 确保在各种构建环境下都能编译通过。

通信协议

协议设计

基于 Protocol Buffers 的高效二进制协议，支持语音和控制消息

proto/common.proto

通用消息类型定义，包括用户信息、频道信息、状态枚举和结果码

package nevo.common;

message User {
  uint64 id = 1;
  string name = 2;
  bool muted = 3;
  bool deafened = 4;
}

message Channel {
  uint64 id = 1;
  string name = 2;
  uint64 parent_id = 3;
  repeated User users = 4;
}

enum ResultCode {
  OK = 0;
  ERROR_AUTH_FAILED = 2;
  ERROR_PERMISSION_DENIED = 3;
  ERROR_CHANNEL_NOT_FOUND = 4;
}

proto/voice.proto

UDP 语音包结构，包含序列号、加密元数据和 FEC 前向纠错信息

package nevo.voice;

message VoicePacketHeader {
  uint32 sequence_number = 1;
  uint64 sender_id = 2;
  uint64 channel_id = 3;
  uint32 timestamp = 4;
  bool last_frame = 5;
  uint32 fec_payload_size = 6;
  bytes nonce = 7;
  bytes auth_tag = 8;
  bool tcp_tunnel = 9;
}

proto/control.proto

控制消息定义，包括认证、频道管理、权限同步等操作

package nevo.control;

message AuthRequest {
  string username = 1;
  bytes password_hash = 2;
}

message ChannelJoinRequest {
  uint64 channel_id = 1;
}

message PermissionUpdate {
  uint64 user_id = 1;
  uint64 channel_id = 2;
  uint32 permissions = 3;
}

语音通讯流程

1

音频采集

miniaudio 从麦克风采集 48kHz PCM 音频数据，封装为 20ms 帧（960 采样点）

2

Opus 编码

每帧音频通过 Opus 编解码器压缩，带内 FEC 前向纠错，自适应码率 6-510 kbps

3

XChaCha20-Poly1305 加密

使用会话密钥对编码后的语音包加密，每个包使用独立的随机 nonce，自动密钥轮换

4

网络传输

UDP 直连或 TCP 隧道传输，JitterBuffer 去抖接收，多流混音后通过 miniaudio 播放

关于 NEVO

NEVO 是一款专为实时语音通讯设计的开源项目，采用 C++20 构建高性能跨平台架构。 支持端到端加密、低延迟传输和复杂网络环境下的 NAT 穿透。

核心模块

  • nevo_core - 核心库
  • nevo_network - 网络库
  • nevo_client - 客户端
  • nevo_server - 服务端
  • nevo_ui - 用户界面

技术栈

  • C++20 / Qt 6
  • Boost.Asio
  • miniaudio + Opus
  • XChaCha20-Poly1305
  • Protocol Buffers
